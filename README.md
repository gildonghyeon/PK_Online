# PK Online ⚽

11미터의 승부, 단 한 번의 킥. 브라우저에서 바로 하는 3D 승부차기 게임입니다.

**▶ 플레이하기: https://gildonghyeon.github.io/PK_Online/**

설치할 것 없이 PC와 모바일 브라우저에서 모두 플레이할 수 있어요.

## 게임 모드

- **싱글 플레이**: AI와 승부차기 대결. 난이도는 쉬움, 보통, 어려움 중에서 고를 수 있어요. AI는 경기 중에 내 킥 방향과 다이빙 습관을 기억하고 읽어냅니다.
- **토너먼트**: 8팀 녹아웃(8강 → 4강 → 결승). 상대 팀 7곳은 팀마다 성향이 달라요. 강슛파, 구석 감아차기 장인, 멈칫 마스터, 파넨카를 즐기는 팀, 늦게 뜨는 키퍼 등이 있어요. 진행 상황은 브라우저에 저장됩니다.
- **멀티 플레이**: 한 화면에서 친구와 번갈아 대결해요.
- **온라인 대전**: 방 코드로 다른 기기의 친구와 대결해요. Claude 아티팩트 런타임에서만 동작합니다.

## 조작법

| | PC | 모바일 |
|---|---|---|
| 키커 조준 | 마우스 / 방향키 | 조이스틱 |
| 슛 파워 | 스페이스·클릭을 눌렀다 떼기 | 슛 버튼을 눌렀다 떼기 |
| 킥 종류 | 1 감아차기 · 2 인스텝 · 3 파넨카 | 화면 버튼 |
| 멈칫 (한 화면 멀티 제외) | 달려가는 중 스페이스 누르고 있기 | 멈칫 버튼 |
| 키퍼 이동·다이빙 방향 | 방향키 | 조이스틱 |
| 다이빙 | 스페이스를 누르는 순간 | 다이빙 버튼 |

키커는 10초 안에 차야 해요. 시간이 지나면 골대 정중앙으로 자동 킥이 나갑니다.

## 특징

- **실제 같은 공 물리**: 중력, 공기 저항, 마그누스 효과(회전으로 휘는 공)를 계산합니다. 오른발 감아차기는 안쪽으로 휘어요.
- **키퍼 판정**: 화면에 보이는 키퍼 자세 그대로 손·팔·몸·다리의 충돌 범위를 계산합니다. 강한 슛은 손을 맞고도 들어갈 수 있어요.
- **심리전**: 멈칫으로 키퍼를 먼저 뛰게 하고, 파넨카는 키퍼가 먼저 뛸 때만 통해요. 키퍼는 원하는 순간에 직접 다이빙합니다.
- **선수 꾸미기**: 헤어스타일, 머리 색, 피부색, 표정, 유니폼, 축구화를 고를 수 있어요. 선수 몸은 관절에 따라 휘어지는 하나의 표면으로 만들었어요.
- **기록**: 경기 후 슛 지도로 내가 찬 위치와 결과를 볼 수 있어요. 킥 준비 중에는 지금 차는 팀의 전적이 보여요.
- **사운드**: 관중 함성, 박수, 효과음을 모두 Web Audio로 합성했어요. 외부 소리 파일은 쓰지 않습니다.

## 직접 실행하기

빌드 과정이 없는 정적 웹페이지입니다. 폴더를 내려받은 뒤 아무 웹 서버로 열면 됩니다.

```bash
npx serve .
```

```bash
python -m http.server 8000
```

3D 렌더링은 CDN의 [three.js](https://threejs.org/) r128을 사용하고, 글꼴은 Google Fonts에서 불러옵니다. 그래서 인터넷 연결이 필요합니다.

## 구조

```
index.html          화면 구성 (로비, 경기 HUD, 동전 던지기, 결과, 토너먼트)

js/audio.js         효과음·관중 소리 합성
js/avatar.js        선수 모델 (뼈대에 붙어 휘어지는 몸, 유니폼, 얼굴)
js/stadium.js       경기장, 골대, 그물, 관중석
js/physics.js       공 물리 (공기 저항, 마그누스 효과, 키퍼 충돌)
js/ai.js            AI 키커·골키퍼 (팀 성향, 상대 습관 학습)
js/lobby.js         로비와 선수 꾸미기 미리보기
js/online.js        온라인 대전 (Claude 아티팩트 런타임 전용)
js/game.js          경기 진행, 애니메이션, 판정
js/tournament.js    토너먼트 대진표와 진행
js/main.js          진입점과 메인 루프
```
